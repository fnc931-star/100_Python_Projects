## 🚀 Getting Started


## 📁 Folder Structure

Each project follows a **consistent modular structure** — logic, visuals, and entry point are always separated:

```
100_Python_Projects/
│
├── any_project_folder/
|   ├── main.py          # Entry point
|   ├── functionality.py # Core logic
|   └── visual_art.py    # ASCII art & visuals
|
├── LICENSE
├── README.md
└── requirements.txt
```

> 💡 **Pattern:** `main.py` is always the entry point. It imports and calls the other files, then clears the screen after a few seconds once the project finishes.
